VALORANT Maps

Explore the tactical battlegrounds of VALORANT. Each map offers unique gameplay experiences and strategic opportunities.

BIND

⭐ Classic Map

Overview

A two-story map set in a mystical realm. Bind features two bomb sites (A and B) connected by a central teleporter mechanic. The map is known for its vertical gameplay and two separate bomb sites with limited direct connections, forcing teams to use teleporters or take extended routes.

Key Callouts

  • ✓ Site A - Showers, Hookah, Main
  • ✓ Site B - Bath, Lobby, Teleporter
  • ✓ Middle - Garden, Garage, Teleporter Portal

HAVEN

⭐ Classic Map

Overview

The only map with THREE bomb sites (A, B, and C). Haven is a temple-like structure that offers multiple strategic options for both attackers and defenders. The third bomb site adds complexity and requires unique tactical approaches compared to other maps.

Key Callouts

  • ✓ Site A - Lobby, Garage, A Main
  • ✓ Site B - Mid, Rafters, B Main
  • ✓ Site C - Shed, Link, C Main

SPLIT

⭐ Classic Map

Overview

Set in a Japanese city divided by a rope structure. Split features two bomb sites on opposite sides of the map with a central ropes area connecting them. The map emphasizes vertical gameplay with multiple platforms and rooftop areas.

Key Callouts

  • ✓ Site A - Main, Lobby, Rafters
  • ✓ Site B - Main, Vents, Ropes
  • ✓ Middle - Ropes Area, Trophy Room

ASCENT

⭐ Classic Map

Overview

A plant-covered world with a futuristic backdrop. Ascent is a large, open map with multiple avenues and verticality. It features significant open spaces and long sightlines, making it suited for agents with ranged abilities and snipers.

Key Callouts

  • ✓ Site A - Main, Lobby, Catwalk
  • ✓ Site B - Main, Lobby, Market
  • ✓ Middle - Arcade, Bell Tower, Main

ICEBOX

❄️ Modern Map

Overview

Set in a frozen facility with icy terrain. Icebox features unique mechanical elements including a rotating cargo container and ziplines for traversal. The map emphasizes verticality with multiple levels and unique navigation options.

Key Callouts

  • ✓ Site A - Green, Main, Rafters
  • ✓ Site B - Kitchen, Blue, Yard
  • ✓ Middle - Connector, Cargo, Cubby

BREEZE

🏖️ Modern Map

Overview

A tropical island map with extensive open areas and long sightlines. Breeze is known for being a large, open map with minimal cover, favoring long-range combat and tactical play. It features unique destructible structures and open courtyard areas.

Key Callouts

  • ✓ Site A - Main, Lobby, Tower
  • ✓ Site B - Main, Pillar, Kitchen
  • ✓ Middle - Courtyard, Graveyard, Mid Tower

FRACTURE

🌀 Modern Map

Overview

A map divided into two distinct halves by a central channel. Fracture features unique geography where both bomb sites are positioned on the same side of the map, requiring attackers to coordinate different approaches. The map emphasizes teamwork and strategic positioning.

Key Callouts

  • ✓ Site A - Rafters, Rope, A Main
  • ✓ Site B - Dish, Arcade, B Main
  • ✓ Middle - Canals, Bridge, Center

PEARL

✨ Latest Map

Overview

An underwater-themed map with a mystical aesthetic. Pearl features elegant architecture and wide-open spaces with multiple levels of verticality. The map provides excellent opportunities for both aggressive and defensive gameplay with multiple pathway options.

Key Callouts

  • ✓ Site A - Heaven, Lobby, A Main
  • ✓ Site B - Garden, Rubble, B Main
  • ✓ Middle - Court, Bridge, Main

Map Selection & Strategy

  • Learn All Maps: Spend time learning each map's layout, callouts, and strategic positions
  • Know Safe Spots: Identify positions where you can farm Ultimate charge safely
  • Learn Rotations: Understand how to rotate between bomb sites efficiently
  • Practice Spray Control: Each map offers different engagement ranges requiring varied spray patterns
  • Memorize Timings: Know how long it takes to rotate and plan your strategy accordingly
